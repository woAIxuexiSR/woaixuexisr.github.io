{%- comment -%} notes_list_item.html — renders one listing List_Item for a paper. Mirrors the pure NotesRender.render_list_item helper (_plugins/notes_render.rb). The whole item is a single activatable link to the paper's detail page. It shows the title, authors, the Track value as a display-only badge (never a link), the Conference_Label, and each Tag as a display-only badge. It never includes the Markdown body text (no abstract/summary snippet).
